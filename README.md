# Shoes Shop 👟

## Descripción
Shoes Shop es una tienda de calzado desarrollada con React. El proyecto permite visualizar productos y utilizar las funcionalidades implementadas para la compra y administración de la tienda.

## Tecnologías
- React
- JavaScript
- HTML y CSS
- Vite
- React Router
- Bootstrap
- Karma y Jasmine para las pruebas automatizadas

## Requisitos
- Node.js
- npm

## Instalación
Clona el repositorio e ingresa a la carpeta del proyecto:

```bash
git clone https://github.com/freddyrios23/shoes-shop-react.git
cd shoes-shop-react
```

Instala las dependencias:

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

Abre en el navegador la dirección local que indique Vite en la terminal.

## Ejecutar las pruebas

```bash
npm run test
```
