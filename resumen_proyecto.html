Vite + React 19

📌 ¿De qué trata el proyecto?

Es una tienda web de calzado (E-commerce) con catálogo, carrito de compras y autenticación (Login/Registro). Está construida con React 19, modularizada con Atomic Design y estilizada con Bootstrap y CSS moderno.

🛠️ Stack Tecnológico

  • React 19 + Vite: Rendimiento y renderizado por componentes.
  • React Router DOM 7: Navegación entre vistas sin recarga.
  • React-Bootstrap: Componentes de UI listos y responsivos.

🚀 Comandos Básicos

  • npm install : Instala paquetes del proyecto.
  • npm run dev : Inicia el servidor de desarrollo local.
  • npm run build : Compila para producción.

Autenticación

🎯 Conceptos Clave para Aprender

Para crear un formulario en React ("JSX vainilla"), solo necesitas 3 cosas fundamentales:
1. Estados (useState): Para guardar en memoria lo que el usuario tipea en tiempo real.
2. Manejador de Envíos (onSubmit): Función que detiene la recarga de página (e.preventDefault()) y valida datos.
3. Enrutamiento (Link y useNavigate): Para saltar entre Login y Register o ir a Home.

🔐 Estructura del Login (Login.jsx)

Campos requeridos:

  • CORREO ELECTRÓNICO (input con placeholder ejemplo@duoc.cl)
  • CONTRASEÑA (input type password con placeholder ••••••••)
  • Botón: INICIAR SESIÓN (negro, mayúsculas)
  • Enlace: ¿No tienes cuenta? Regístrate aquí
const [email, setEmail] = useState(''); const [password, setPassword] = useState(''); <input type="email" value={email} onChange={(e) => setEmail(e.target.value)} />

📝 Estructura del Registro (Register.jsx)

Campos requeridos:

  • NOMBRE COMPLETO
  • CORREO ELECTRÓNICO
  • CONTRASEÑA
  • CONFIRMAR CONTRASEÑA (valida igualdad)
  • Botón: REGISTRARSE
  • Enlace: ¿Ya tienes cuenta? Inicia sesión aquí
if (password !== confirmPassword) { setError('Las contraseñas no coinciden.'); return; }

🎨 Estilos del Formulario (Tarjeta exacta según la imagen)

Los estilos se encuentran centralizados en src/styles/global.css:

  • .auth-container: Centra la tarjeta horizontal y verticalmente en la pantalla.
  • .auth-card: Tarjeta blanca limpia con borde sutil (#e5e7eb) y sombra suave.
  • .auth-label: Letras en negrita (font-weight: 800), tamaño 12px y mayúsculas.
  • .auth-input: Bordes redondeados de 6px y resalta el foco en negro al hacer clic.
  • .auth-btn: Botón negro (#111111) de ancho completo con texto blanco en mayúsculas.
